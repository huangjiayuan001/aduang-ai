# 🏢 企业级智能文档解析助手 (AI Document Parser)

## 📖 项目简介
基于 Python、Streamlit 和 DeepSeek API 开发的通用型文档解析 RAG 应用。支持上传 TXT 或 PDF 文档，利用大模型进行精准总结、角色化问答，并通过 Prompt 工程有效限制模型幻觉。

## 🛠️ 核心技术栈
- **前端界面**：Streamlit
- **大模型**：DeepSeek API (兼容 OpenAI SDK)
- **文档解析**：pypdf

## ✨ 核心功能
1. **多角色切换**：支持“数据提取专家（输出 JSON）”、“毒舌面试官”、“爆款文案写手”等多种业务场景。
2. **防幻觉机制**：强制 AI 仅基于上传文档内容作答，未提及的内容绝不瞎编。
3. **结构化输出**：可提取关键信息并输出为 JSON 格式，便于后端系统集成。
4. **安全防御**：限制了 5MB 的文件上传拦截，并加入了全局异常捕获，保障程序健壮性。

## ⚠️ 项目边界与局限性
1. 当前版本仅支持**纯文本版** PDF 与 TXT 文件解析。
2. 暂不支持 OCR 技术，无法解析图片扫描版 PDF。
3. 单文件大小限制为 5MB，防止恶意攻击或 Token 超限。
4. 本项目基于长文本直接注入上下文，暂未接入向量数据库（当前为 V1.0 原型版）。
